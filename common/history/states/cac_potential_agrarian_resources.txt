# Place in: common/history/states/00_agrarian_potential.txt
#
# Rewrites the arable_resources of every state region so that only buildings
# that were historically possible AND practiced around 1337 remain.
# Philosophy (from the old Anno 1836 mod): at most 4 agricultural buildings per
# state where possible (staple + livestock/sheep + up to 2 specialties).
# Only Lower Egypt and Sicily are allowed 5.
#
# Staples: wheat, rye, rice, maize (Americas only), millet/sorghum
# Others : livestock, sheep, cotton, tobacco (Americas only), sugar, banana
#          (Old World only), coffee, tea, silk, dye, opium, vineyard, fiber
# Rubber is removed everywhere. Gold fields, oil and subsistence are untouched.
# Exception to the 1337 rule: states with no farming in 1337 and bare islands get
# the colonial-era uses (cattle/sheep ranching, sugar, wine...) - see the last sections.
#
# Each line: s:STATE = { remove... add... }   # final agricultural list
#   W wheat  R rye  RI rice  M maize  MI millet  L livestock  SH sheep
#   C cotton  T tobacco  S sugar  B banana  CO coffee  TE tea  SI silk
#   D dye  O opium  V vineyard  F fiber
# Only differences from the base game are written.
# =============================================================================
